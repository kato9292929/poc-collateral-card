# 実証5：カードの利用上限を予算上限にする

状態：**途中で終了**（2026-11-09）。上限の設定まで確かめ、購入は行っていない

ether.fi Cash の Vault の 1 日の利用上限を $4.05 にして、エージェントの予算上限として効くか（上限内は通り、上限を超える支払いは拒否されるか）を 1 回確かめる。

計画：https://note.com/x402inc/n/naf32f4cea741

順番：実証4 の $5 の支払いより前に行う。実施中は、同じアカウントのほかのカードで支払いをしない（1 日の Vault 上限は全カード共通で、使った額が 24 時間で戻るため）。

## 参照した公式ドキュメント（2026-11-06 確認）

| 対象 | URL | 確かめたこと |
|---|---|---|
| Vault とカードの利用上限 | https://help.ether.fi/en/articles/330661-managing-your-vault-and-card-limits | Vault の上限は Vault ページ右上のアカウントメニュー → Settings → Spending limits で変えられる。1 日の上限（初期値 $100,000、全カード共通、24 時間で戻る）と 1 か月の上限（初期値 $1,000,000）がある。上限を上げても、残高・借入枠を超えては使えない。**下限の金額と、変更がいつ効くかは書かれていない**（変更後の画面で確かめる） |
| 拒否の理由 | https://help.ether.fi/en/articles/262393-why-did-my-transaction-get-declined | アプリの取引履歴で、拒否された支払いの「Decline reason」に理由が出る。ether.fi に届く前に拒否されたものは履歴に出ないことがある |
| 担保と借入（当初の案） | https://help.ether.fi/en/articles/304388-how-does-collateral-and-borrowing-work | 借入枠は Vault の資産額 × 資産ごとの LTV（USDC は 81%） |

## 当初の案からの変更

- **当初の「担保 $5 × LTV 81% で利用枠を決める」をやめ、「Vault の 1 日の利用上限 $4.05 を予算上限にする」に変えた。** 理由：このアカウントの Vault にはすでに約 $1,554 あり（2026-11-06 の画面：Available to spend $1,553.91、Available to borrow $1,258.13）、Borrow モードでは Vault の資産すべてが担保になるので、担保を $5 にできない。資産は動かさない。$1,258.13 ÷ $1,553.92 ≈ 81% で、USDC の LTV 81% とは合っていた
- 支払いは Borrow モードに切り替えず、**Direct Pay のまま**行う
- 支払い先は **Amazon.com の eギフトカード**（金額を自由に入れる、Eメール配送、受取人は自分）
- 上限を超える側の支払いは $4.00

## 手順

1. 人が Vault の 1 日の上限（Daily vault limit）を $4.05 にし、変更後の画面のスクリーンショットを渡す
2. 人が ether.fi のカード（Direct Pay）で、Amazon.com の eギフトカードを **$1** → **$4.00** の順に 1 回ずつ買う。$1 のあと 1 日の残りは $3.05 になり、$4.00 はそれを超える。それぞれの結果のスクリーンショットと、ether.fi アプリの取引履歴の表示（拒否なら理由）を渡す
3. 人が上限を元の値（$100,000）に戻し、戻した画面のスクリーンショットを渡す
4. $4.00 が拒否されたら、取引履歴の拒否理由が「上限超過」か「加盟店側の拒否」かで分けて書く。$1 が通っていれば、ギフトカードそのものは買えるものとして扱う

## 結果

上限の設定の挙動を確かめたところで終えた。Amazon の eギフトカードの購入（$1・$4.00）は行っていない。

| 項目 | 値 |
|---|---|
| 実施日時 | 2026-11-08〜09 |
| 設定画面の名前 | Vault ページのアカウントメニュー → Settings → Spending limits の **Daily Limit / Monthly Limit**（「Daily vault limit」という名前の項目は無い）。画面の説明は「These limits apply to the combined total of all purchases and payments made with any card linked to this account.」 |
| 入れられる値 | **整数のみ**。$19.35 では保存ボタンが押せず、$4・$5・$99・$100 は押せた。$5 で保存できた（Limit Updated）ので、下限は少なくとも $5 以下 |
| 変更が効くまでの時間 | 保存直後に一覧の表示が新しい上限（$5.00）に変わった |
| すでに使った額の扱い | 上限を下げても、直近の枠ですでに使った額（$15.29）がそのまま数えられる。上限を下回ると「**exceeded by $10.29**」と赤字で出る |
| 枠が戻る時期 | 「Refreshes in about 21 hours」（1 日の枠）、「Refreshes in 22 days」（1 か月の枠）と表示 |
| $1 の成否 | 未実施 |
| $4.00 の拒否の有無と文言 | 未実施 |

分かったこと：1 日の上限は、その日すでに使った額を含めた合計にかかる。予算として使うには、上限を「すでに使った額 ＋ 予算」の整数に設定する必要がある。上限を予算の額だけにすると、その日にほかの支払いがあれば最初の 1 回から止まる。
